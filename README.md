# AutoRozsudek.cz — web v1

První funkční prototyp veřejné prezentace.

## Soubory
- `index.html` — obsah stránky
- `styles.css` — vzhled a responzivita
- `script.js` — mobilní menu
- `assets/` — sem později přijdou vlastní skutečné fotografie

## Důležité
Tato verze záměrně nepoužívá AI fotografie aut. Šedý blok v hero sekci je placeholder pro budoucí reálnou fotografii.

Klientské protokoly, osobní údaje, fotografie konkrétních zakázek ani přístupové údaje se nemají ukládat do tohoto repozitáře. Privátní klientská část bude řešena samostatně se zabezpečeným úložištěm a autentizací.
